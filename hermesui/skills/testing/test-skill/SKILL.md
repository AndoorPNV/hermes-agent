# Test Skill

Минимальный тестовый скилл для проверки, что создание, индексация и загрузка скиллов в Hermes работают.

## Когда использовать

- Проверка `skill_manage(action='create')`.
- Проверка, что `skill_view(name='test-skill')` возвращает содержимое.
- Отладка конфигурации каталога скиллов.

## Действие

Ничего не делает. Если этот скилл загружен — значит цепочка создания/загрузки исправна.

## Проверка

```
skill_view(name='test-skill')
```

Должен вернуть этот текст без ошибок.
