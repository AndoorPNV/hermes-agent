# Промты для монтажа учебных скринкастов (Revit)

Генерирует готовые к вставке промты для AI-видеоредактора: черновой монтаж,
акценты на интерфейсе, субтитры, чек-лист шагов, маркеры интерактивности, звук,
экспорт. Скилл НЕ монтирует видео и не правит курс — он выдаёт текст промта
с заполненными слотами и предупреждениями о том, что модель-редактор может
выдумать. Все формулировки по умолчанию на русском.

## When to Use

- «Сделай промт для монтажа ролика про <тема урока>»
- Нужен промт под фрагмент курса «Создание эталонной модели в Revit»
- Нужно единообразно оформлять серию уроков курса (один шаблон на все уроки)

Не использовать для: реального монтажа/рендера (`terminal` + ffmpeg — отдельная
задача), для написания сценария урока с нуля, для курсов не по Revit без
переделки раздела `references/revit-ui-zones.md`.

## Входные слоты

Собрать до генерации. Отсутствующие — спросить у пользователя, не выдумывать.

| Слот | Пример | Обязателен |
|---|---|---|
| `{файл}` | `M1_helpgn_zayavka.mp4` | да |
| `{модуль}` | `МОДУЛЬ 1: ПОДГОТОВКА И НАСТРОЙКА МОДЕЛИ` | да |
| `{тема_урока}` | `Подача заявки на модель через HelpGN` | да |
| `{цель}` | `Ученик умеет создавать заявку` | да |
| `{аудитория}` | `Архитекторы концепции` | да |
| `{можно_вырезать}` | паузы, оговорки, дубли, лишние переключения | да |
| `{формат}` | `MP4, 16:9, 1080p` | да |
| `{длительность}` | `6 мин исходник → 4 мин финал` | желательно |
| `{экранные_элементы}` | лента, свойства, диспетчер проекта | желательно |
| `{термины}` | `заявка`, `эталонная модель`, `HelpGN` | желательно |

## Procedure

1. **Сверить слоты.** Все обязательные заполнены или явно помечены `[уточнить]`.
   Критерий: в готовом промте нет ни одного слота без значения и без пометки.
2. **Взять шаблон** из `templates/prompt-template.md`, подставить значения.
   Критерий: блоки «Контекст ролика» и «Ограничения» заполнены дословно
   из слотов, без пересказа.
3. **Сузить акценты под урок.** Не перечислять все панели Revit подряд — только
   те, что реально участвуют в уроке (см. `references/revit-ui-zones.md`,
   карта безопасных зон оверлеев). Критерий: ≤ 5 элементов интерфейса на ролик.
4. **Добавить блок «Маркеры интерактивности»** таблицей: таймкод, тип, задание,
   правильный ответ, обратная связь при ошибке. Критерий: у каждого маркера
   есть все пять полей; 1–3 маркера на 4–6 минут, не больше.
5. **Вставить страховку от галлюцинаций** — блок «Нельзя выдумывать» с явным
   перечнем того, что модель-редактор обязана не добавлять (команды Revit,
   пункты меню, требования регламента, названия кнопок HelpGN). Критерий: блок
   содержит запрет на новые команды и на «улучшение» текста субтитров.
6. **Проверить по чек-листу** в конце этого файла и отдать промт целиком,
   готовым к копированию, без комментариев внутри тела промта.

## Правила формулировок

- Таймкоды — только относительные или `[по исходнику]`; абсолютные цифры
  выдумывать нельзя, их ставит редактор после просмотра.
- Субтитры: цитировать речь преподавателя, не перефразировать команды.
- Горячие клавиши и параметры выделять отдельным стилем (`KB`, `PARAM`),
  но не придумывать сочетания — писать только те, что названы в записи.
- Не ускорять учебные действия сильнее 1.25× и не ускорять моменты ввода
  значений в поля — ученик не успевает читать. Паузы резать, темп — нет.
- Звук: нормализация голоса, шумоподавление; музыку не добавлять, если её нет
  в исходнике; если есть — не громче −18 dB под голосом.
- Экспорт: указывать кодек/контейнер/разрешение/соотношение и `-movflags +faststart`
  для веба, если формат MP4.

## Примеры

- `templates/prompt-template.md` — пустой шаблон со слотами (RU).
- `templates/example-helpgn.md` — заполненный пример для урока
  «Подача заявки на модель через HelpGN».
- `references/revit-ui-zones.md` — зоны интерфейса Revit: что подсвечивать,
  чем нельзя перекрывать, разрешённые термины.

## Pitfalls

1. **Модель-редактор дописывает команды Revit.** Всегда оставлять запрет на новые
   команды/пункты меню: без него в субтитрах появляются несуществующие кнопки.
2. **Оверлеи поверх критичных зон.** Стрелка или зум поверх панели свойств или
   диалога ввода прячет ровно то, что объясняют. Держать оверлеи в полях кадра
   (см. карту зон), не поверх активного диалога.
3. **Слишком много интерактивов.** Больше трёх маркеров на короткий фрагмент —
   ролик превращается в тест. Ставить интерактив только на смысловые развилки.
4. **«Динамичный монтаж» понимают как ускорение.** Явно писать: режем паузы,
   а не ускоряем действия.
5. **Пользователь даёт обрезанный промт** (обрывается на полуслове) — не
   додумывать конец: восстановить по смыслу и пометить `[восстановлено: ...]`
   в одном месте, чтобы он подтвердил.

## Verification Checklist

- [ ] Заполнены все обязательные слоты, `[уточнить]` не осталось
- [ ] Контекст урока дословно из слотов, а не пересказ
- [ ] ≤ 5 акцентов на интерфейсе, все — участники урока
- [ ] Маркеры интерактивности: 5 полей у каждого, 1–3 штуки
- [ ] Блок «Нельзя выдумывать» присутствует и запрещает новые команды
- [ ] Оговорено: режем паузы, но не ускоряем действия >1.25×
- [ ] Экспорт: контейнер, кодек, разрешение, соотношение
- [ ] Промт отдаётся одним копируемым блоком без вложенных комментариев
